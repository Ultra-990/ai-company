# Kontrakty domenowe

Warstwa kontraktów domenowych definiuje stabilne modele systemu AI Company.

Modele powinny być:
- niezależne od FastAPI,
- niezależne od dostawcy LLM,
- walidowalne,
- serializowalne,
- łatwe do testowania,
- pozbawione efektów ubocznych.

Planowane kontrakty:
- Task
- Agent
- Department
- Tool
- ApprovalRequest
- AuditEvent
- Decision
- MemoryRecord
