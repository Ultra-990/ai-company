# Organization OS — domena danych

Moduł zawiera fundament domeny Organization OS:

- OrganizationNode — drzewo organizacyjne i ważony postęp,
- Task — zadania przypisane do węzłów,
- Evidence — dowody wykonania,
- Alert — powiadomienia, ryzyka i blokady,
- Agent — podmioty wykonawcze / analityczne,
- WorkspacePreference — preferencje widoku i workspace.

Warstwa API oraz migracje zostaną dodane po dopasowaniu do istniejącej
konfiguracji bazy danych aplikacji.
