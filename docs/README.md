# Dokumentacja projektu

## Cel

System służy do zarządzania zadaniami, procesami i agentami wykonawczymi.

## Główne elementy

- Task API
- Panel postępu
- Baza SQLite
- System etapów zadań
- Automatyczna dokumentacja statusu
- System agentów
- Audyt i bezpieczeństwo

## Dostępne widoki

- `/health` — kontrola działania aplikacji
- `/progress` — panel postępu
- `/api/tasks` — API zadań
- `/api/progress` — dane postępu
